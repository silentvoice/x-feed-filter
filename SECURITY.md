# Security policy

## Supported versions

Only the latest release gets security fixes.

## Report a vulnerability

> [!IMPORTANT]
> Do not open a public issue for a security problem.

1. Go to the [Security tab](https://github.com/silentvoice/x-feed-filter/security) of the repository.
2. Click **Report a vulnerability**.
3. Describe the problem, the steps to reproduce it, and the possible effect.

The maintainer replies in 7 days or less. After we correct the problem, we publish a security advisory. We give credit to the reporter, if the reporter agrees.

## Scope

These problems are in scope:

- The extension sends post content or settings to a server.
- A web page can read or change the settings of the extension.
- A web page can run code in the context of the extension.
- The extension requests a permission that it does not need.
