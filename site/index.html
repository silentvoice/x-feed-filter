A calmer feed for X.

Tell Lull what you do not want to see, in your own words. A small AI model on your computer reads each post and blurs the ones that match. Your feed never leaves your device.

Filters in plain language

Turn on a built-in filter, or write your own. Lull reads each filter as a yes-or-no question about each post.

Private by design

There is no Lull server. There is no account. Lull does not collect analytics.

On-device AI

Lull runs Liquid AI d1-omni-600M with WebGPU. It is a decision model: it gives a probability for each filter, in one step.

Fast

About 50 ms for each post with five filters on an Apple M5 Max. New posts stay blurred until they are checked, so filtered content never flashes.

Works without a GPU

Computers without WebGPU use a smaller zero-shot model on the CPU. Lull selects it automatically.

Blur or hide

Blurred posts show the reason and a Show button. Or hide filtered posts completely.

You set the strictness

One slider sets how sure the model must be. Muted words and an allowlist work too.

Open source

Apache-2.0 code, tests that compare the model with the original Python, and plain documentation.

How it works

Lull has three parts. All of them run in your browser.

  1. Find

    A content script finds each post on x.com and reads its text, quoted post, and image descriptions.

  2. Decide

    The model reads each post with each filter and gives the probability that the post matches.

  3. Calm

    If a probability is above your threshold, Lull blurs or hides the post. Errors show the post, never hide it.

Try it

Lull is not in the Chrome Web Store yet. Build it from the source:

git clone https://github.com/silentvoice/x-feed-filter.git
cd x-feed-filter && npm install && npm run build

Then open chrome://extensions, turn on Developer mode, click Load unpacked, and select .output/chrome-mv3. The first use downloads the model (about 245 MB).

Questions

Does Lull send my feed anywhere?

No. The model runs in your browser. The only network request downloads the model from Hugging Face, one time.

Which computers work?

Desktop Chrome. A Mac with Apple silicon gives the best speed. Other computers with WebGPU also work, and computers without WebGPU use the smaller CPU model.

What if a post is filtered by mistake?

Click Show to see it. Move the strictness slider, or make the filter description more specific.

What is the license?

The code uses Apache-2.0. The d1 model has its own license (LFM Open License v1.0), which is free for organizations with less than USD 10 million annual revenue.
