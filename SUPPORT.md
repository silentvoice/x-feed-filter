# Support

- **Questions and ideas:** use [GitHub Discussions](https://github.com/silentvoice/x-feed-filter/discussions).
- **Bugs:** open a [bug report](https://github.com/silentvoice/x-feed-filter/issues/new?template=bug_report.yml).
- **Wrong filter results:** open a [wrong filter result report](https://github.com/silentvoice/x-feed-filter/issues/new?template=wrong_filter_result.yml).
- **Security problems:** use the procedure in [SECURITY.md](SECURITY.md).
